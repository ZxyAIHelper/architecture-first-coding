# 开源架构 skill 与整体架构案例

日期：2026-11-21。状态：范围已按最新要求更新。

## 需求

- 将全局 architecture-first-coding 作为独立公开 GitHub 仓库维护，采用 MIT 许可证。原版 skill 及四份参考文件保持不变。
- 使用当前正式名称《余烬庭院 · 二十波》和《街坊商场》，全文不使用旧游戏名或本机旧目录名。
- 两个示例覆盖游戏整体架构，包括五层职责、主要系统、状态所有者、装配与生命周期、命令与查询边界、关键链路及失败恢复。
- 每个游戏附一张可直接在 GitHub 阅读的 PNG 整体架构图，另附一张 skill 应用流程图。图与正文统一，并明确箭头语义和视图粒度。
- 英文 README 额外嵌入一张通用五层架构图，使用英文标签说明各层职责、状态归属、向下依赖及最外侧装配；与原版 skill 的依赖白名单一致。
- 示例只允许架构：文字、表格、架构图片。不发布实现源码、伪代码、接口签名代码块、测试、运行脚本或执行命令。删除此前发布的可运行模型、验证脚本与对应 CI；本次不重写 Git 历史。
- 中英文仓库入口均更新为架构案例导向，安装方式使用文字说明。
- 英文入口、英文案例指南、英文整体案例及其引用图片全部使用英文，不混入中文标签或中文游戏名；中文版本单独保留。英文生存游戏名沿用游戏本地化的 Ember Garden；经营游戏使用 Neighborhood Mall 作为英文译名。
- 案例来自当前规格及相关实现的只读核对，区分实际观察到的边界与 skill 的设计约束，不宣称完整代码审计或游戏运行验收。
- 不修改两个游戏项目，不发布完整源码、数值目录、素材、存档、内部研究资料、凭据或本机路径。

## 验收

1. 原版五份 skill 文件及 Git 对象均与全局源文件字节一致。
2. 两个当前游戏名在介绍、案例和图中一致，旧名称无残留。
3. 两个整体案例及中英文各三张架构图完整，文字与图中的职责、所有者及依赖约束一致。
4. 发布文件仅包含 Markdown、PNG、许可证及必要 Git 文本属性，不含实现源码、执行脚本、测试、CI 或新增代码块。
5. 本地链接、图片完整性、版面、私密内容与 Git 差异检查通过，推送后本地与远端提交一致。
6. 英文 Markdown 不含汉字，嵌入英文图片并链接英文案例；中文入口仍可访问独立中文内容。
